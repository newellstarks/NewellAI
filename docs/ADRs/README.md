## Template

When adding an ADR, use:

```markdown
# ADR-NNNN: Title

## Status
Proposed | Accepted | Superseded | Deprecated

## Context
What forces us to decide?

## Decision
What did we choose?

## Consequences
What becomes easier or harder?
```

Name files `NNNN-kebab-title.md` and link them here.
